# P5 扩容草稿与集中审核

此目录是审核准备区，不是已审核课程。运行本机开发服务后，可从学习空间的“查看完整草稿”进入只读预览；草稿不会进入正式学习流程或公开发布包。

- `primary-300.json`：原 30 条英语样板，加 270 条从原词库 A1 候选中选出的词和日常例句。新增词义、例句及现有媒体沿用原项目素材，按 CC BY 4.0 署名；这些例句并未经过儿童适龄审校，主题分组也是临时的。
- `hanzi-100.json`：原 20 字样板，加 `hanzi-expansion.tsv` 中的 80 字新编候选短句。课程数据尚未绑定新增媒体。
- `hanzi-image-candidates.json` / `hanzi-image-review.csv`：80 张新增汉字候选图的路径、来源、文件校验值和审核说明；64 张复用原图鉴，16 张使用原插画作参考新生成。亲属关系及“今天／明天”等画面不能单独保证识别题唯一答案，须先审校。
- `audio-candidates.json`：230 条仅供听审的系统语音候选，包括 100 条汉字单字、100 条汉字例句和 30 条英语例句。文字、语言、声音、时长和文件校验值逐条记录；这些录音的使用与再分发条件尚未核实，不可直接发布。
- `media-review.csv`：400 条文本、候选图片和音频集中审核表；`review-queue.csv` 保留初次制作时的缺口记录。所有内容和媒体均待人工审核。

结构检查通过不等于内容适龄、翻译准确、图片符合含义或音频适合儿童。正式课程字段中仍缺 30 条英语例句录音，以及 80 幅汉字插画、100 条汉字单字录音和 100 条汉字例句录音；对应候选素材已单独准备，但尚未完成审核、授权确认或绑定。所有 400 条均未人工审校。新增音频必须确认合法来源、可分发授权及其与文本完全一致，不能把设备朗读冒充可发布的录音。

`npm run drafts:prepare` 可按当前样板、原词库和 TSV 重新生成这三份文件。脚本拒绝覆盖内容不同的既有文件，避免覆盖后续编辑。草稿检查可使用 `npm run check:courses -- --input data/drafts/primary-300.json --expected-version 0.1.0-draft`，汉字文件同理；加 `--release` 时预期因未完成审校和媒体而失败。
