# 课程内容审校表

这两份表对应当前学习空间实际使用的课程版本：

- `primary-starter-0.4.0-draft.csv`：基础英语 300 词，继续调整样板例句以符合插画。
- `primary-starter-0.3.0-draft.csv`：旧版审校记录，保留以便核对，不作为当前版本的结果。
- `primary-starter-0.2.0-draft.csv`：旧版审校记录，保留以便核对，不作为当前版本的结果。
- `hanzi-starter-0.7.0-draft.csv`：汉字启蒙 300 字，继续打磨样板词语及图文语境。
- `hanzi-starter-0.6.0-draft.csv`：旧版审校记录，保留以便核对，不作为当前版本的结果。
- `hanzi-starter-0.5.0-draft.csv`：旧版审校记录，保留以便核对，不作为当前版本的结果。
- `hanzi-starter-0.4.0-draft.csv`：旧版审校记录，保留以便核对，不作为当前版本的结果。

CSV 使用 UTF-8 BOM，可用常见表格软件打开。每行包括课程版本、主题、文字、例句、当前版本的图片与录音路径、来源，以及系统提示的待处理项。图片路径相对于项目目录；也可以在本机学习空间点击「检查课程内容」逐条查看图文。

建议依次检查文字及适龄性、图片和目标含义是否一致、朗读是否准确，再填写“文字审校”“图片审校”“发音审校”“审校人”“审校日期”和“修改建议”。英语 30 条例句目前没有预录音；汉字目前使用设备普通话朗读词语，没有课程预录音。请区分设备朗读和可分发录音，不要把设备朗读写成已制作录音。

表格是供人工记录的工作副本：填写表格不会自动修改网站内容、变更课程状态或生成已审核证明。保存时保持条目 ID 和课程版本，后续修改需明确核对并回写课程内容；内容变更必须使用新的课程版本。

运行 `npm run export:review` 可为当前课程版本创建对应表格。若同名文件已经存在，命令会保留原文件，不覆盖已填写的审校记录；如需重新导出，请先把已有文件另存，再运行命令。课程升级后会产生新版本文件，原版审校记录继续保留，需按条目和具体改动重新核对。
