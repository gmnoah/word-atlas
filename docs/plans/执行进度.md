## 2026-10-27 第三次推进：T07 统一加载边界适配

完成后立即勾选 PLAN 的 T07。在 `src/atlas/types.ts`、`src/atlas/data.ts` 与 `src/atlas/context.tsx` 中建立统一 Course 加载边界：

- **统一契约与接口**：定义 `Course` 接口，雅思开放词库与私有词库作为 legacy 课程适配接入，样板课程（`primary-starter`、`hanzi-starter`）作为 preview 课程接入。
- **向后完全兼容**：现有 `Atlas` 接口完全保留（`words`、`byId`、`topics`、`cefr`、`entry`、`peek`、`img`、`audio`），原雅思所有页面和组件无需改动；新增 `manifest`、`toLearningEntry` 与 `asLearningEntry` 将雅思条目无损投影为统一 `EnglishEntry`。
- **资源地址零改动**：雅思静态资源（`/atlas/index.json`、`/atlas/entries/*.json`、`/atlas/img/*.webp`、`/atlas/audio/*/*.mp3`）路径与生成机制 100% 保持不变，同时支持 `import.meta.env.BASE_URL` 子路径部署。
- **按需加载与代码分割**：`loadCourse("word-atlas-open")` 不拉取新课程；`loadCourse("primary-starter")` 动态导入样板包，不拉取 7,298 词雅思索引。`CoursePreview` 继续保持独立构建分块（`CoursePreview-*.js`）。
- **异步竞态隔离与容错**：
  - `AsyncScope` 提供单调递增令牌，切换学员或课程时立即废弃旧令牌，防止延迟响应污染新学员上下文。
  - `loadCourse` 支持并发请求合并（deduplication），失败请求及时清理挂起态以便重试；支持 `AbortSignal` 取消不留坏缓存。
  - `useEntry` 和 `useCourseEntry` 内置请求时效性保护，路由/参数切换时立即丢弃过期结果。
- **保护与边界验证**：初高中待开放课程与未知课程明确拒绝，未受信任的损坏 JSON 和条目 ID 给出清晰错误提示。
