# 基础英语与汉字启蒙：旅程首页与学习记录方案

日期：2026-10-28。状态：T48–T55 已部分实施，具体进度和验证结果以《开发实施计划》和《执行进度》为准；长期活动归档及完整联调仍未完成。本方案承接用户提出的动态界面与统计需求；P6 家庭试用继续暂缓，T43–T47 的人工审校不因此标记完成。以下现状、估算和验证清单保留规划时的基线。

## 1. 产品目标与现状

让两门课程都有完整的“今天做什么 → 继续学习 → 看见自己的探索 → 家长了解学习记录”体验。动态界面首先表示真实学习状态发生变化，其次才是轻量动画。

本次依据本地代码检查：

| 当前能力 | 已有实现 | 本轮补齐 |
| --- | --- | --- |
| 雅思旅程 | Today 主视觉、今日计划、周活动和 Galaxy；Me 累计与趋势 | 复用视觉语言，不复用成人掌握阈值或连续打卡压力 |
| 基础英语 | PrimaryJourney 今日小课、续学、收藏；主题自选 | 独立旅程首页、可变化的主题地图、学习足迹 |
| 汉字启蒙 | HanziMap 平面主题路径、认一认/只读一读 | 今日共读建议、最近续学、按实际接触变化的地图 |
| 家长面板 | 两课程累计看过、复习卡、收藏、到期数量 | 近期活动、独立/提示/协助记录及简明解释 |
| 持久化 | PrimaryProgress 保存 introduced、cards、favorites、applied；断点保存当前会话 | 可备份的活动摘要与每日聚合，支持历史完整性说明 |

目前没有持久化的完整逐日首次作答明细，不能从复习卡倒推历史正确率、协助次数或学习时长。会话结束页的当次统计不等于已有历史统计。

## 2. 页面与导航

保持统一品牌、字体、纸感、深浅主题与全量图鉴。在现有 explore 路由下增加 view 参数，避免另造独立应用。以下视图入口已接入，验收状态见执行进度：

- 英语旅程：`#/explore?course=primary-starter&view=journey`。
- 汉字旅程：`#/explore?course=hanzi-starter&view=journey`。
- 对应图鉴：同一课程 `view=atlas`。
- 对应学习记录：同一课程 `view=records`。

现有不带 view 的课程链接保留当前图鉴/主题入口语义；空间选择页新增明确的“开始旅程”和“打开图鉴”。带 entry 的旧词/字卡链接继续优先打开原条目，关闭后回到合法的来源视图。非法 view 安全回退，不建立空白页面。浏览器前进、后退和刷新保持视图。

英语导航：今日旅程 / 全部图鉴 / 学习足迹，家长设置保留原入口。汉字导航：一起探索 / 全部字卡 / 家长记录；详细数字放在家长侧。小课中隐藏非必要导航。首期仍服务当前小学课程，不提前展示未实现的初高中能力。

## 3. 两门课程如何呈现

### 基础英语：主题探索旅程

- 首屏使用现有统一风格的情境插画，展示学员昵称、课程、今日建议和一个主行动。
- 主行动依次考虑有效未完成小课、适量回顾、推荐新内容；明确“继续哪一课”，不能只检查断点键是否存在。
- 默认突出最近主题与推荐主题，完整主题仍可展开或进入图鉴查看，不把 300 个词一次铺成复杂地图。
- 地图站点显示“还没探索 / 看过部分 / 这一站都看过”，依据去重接触记录；练习情况另示，不把看过当作掌握或通关。主题始终可自由进入。
- 收获使用实际词卡缩略图；完成一次小课后地图轻微点亮，刷新不重复播放庆祝动画。

### 汉字启蒙：亲子生活地图

- 主视觉延续复古自然图鉴，地图保持二维大站点，不加载三维星图。
- 主行动默认“一起读一读”，有有效断点时“接着上次读”；“认一认”作为明确的可选活动。模式与断点分开恢复。
- 优先露出最近主题与少量生活主题，32 个主题仍可完整访问；不把家长每日建议变成孩子必须完成的识字指标。
- 共读后场景呈现“来过/读过”，只有符合题型资格的识别作答进入对应记录；图字配对、照样找字与共读不冒充独立识字。
- 结束给一条现有生活互动提示和返回入口，不自动开启下一关。

### 统一动态规则

动态由真实进度、当前学员和课程驱动。新用户、进行中、今日已活动、暂无新内容、记录加载失败分别设计；读取失败不能显示为零进度。普通动画只在进入或状态变化时短暂发生，沿用现有 motion 与 CSS token，减少动态效果时使用静态状态。不开启持续闪烁、循环漂浮、自动背景音或强制开场。首期优先复用现有授权图片；若以后新增主视觉，另记来源与授权并核对统一风格。

## 4. 统计指标与显示口径

| 指标 | 统计定义 | 展示位置与限制 |
| --- | --- | --- |
| 累计看过 | 当前课程有效条目 ID 中，具有初见记录的去重数量 | 儿童可见；称“看过”，不称“学会” |
| 主题探索 | 主题内看过的去重条目数 / 当前主题条目数 | 地图；重叠主题可分别展示，全课程总数去重 |
| 本次/近期独立答对 | 可识别题型的首次作答、无提示/协助且正确 | 家长记录；不是识字量或全部技能掌握量 |
| 提示后/协助后答对 | 首次作答正确，按最终支持级别互斥归类 | 家长记录；协助不能更新识别掌握结论 |
| 独立首次正确率 | 独立首次答对 / 独立首次有效作答 | 第二批再做；显示题数，分母为零显示“暂无记录”；排除重试、跳过、媒体失败、共读、拼写及不合格题型 |
| 共读活动 | 明确以共读模式进行并产生实际内容接触的活动 | 汉字家长区；与认一认分列，不从全部 introduced 反推 |
| 最近 7 天活动 | 按记录日期展示接触与有效练习活动 | 不设连胜/断签、排名或补打卡，0 次不是失败 |
| 前台活动时长 | 可验证的会话前台累计时间增量 | 第二批再做；后台、关闭页面、离线间隔不累计；不称专注力 |
| 收藏与建议回顾 | 现有收藏、调度结果并按会话上限选取 | 旅程入口；儿童不展示积欠复习压力 |
| 资源失败、跳过、主动结束 | 分开记录实际事件 | 家长详情解释，不计作答错误；主动停止不算学习失败 |

首期记录页优先展示累计看过、最近活动、独立/提示/协助次数及主题足迹。趋势不是能力诊断；不做年级能力排名、听说读写综合评分、预测考试成绩。

## 5. 数据与安全实施约束

1. 增加独立的课程活动记录模块，按 profileId + courseId 隔离。字段至少包括 schema 版本、sessionId、内容版本、活动模式、时间、可验证的当次结果与记录覆盖起点；不收集真实姓名、生日和远程埋点。
2. 在现有小课保存节点同步记录可恢复的会话摘要，而非只在正常完成时记录。首次结果按 sessionId + contentId 去重；重试与资源失败需有独立稳定事件标识，不能重复累计。刷新、恢复、返回结果页、导入同一备份不重复增加数据。
3. 摘要按同一会话更新，累计值使用增量或替换后重算，不能把完整 activeMs 每次相加。按设备本地日期分桶，保留事件时间与当时偏移；跨午夜分割活动增量，切换时区不重算既有日期。时钟回拨或异常时长不得产生负值。
4. 初期设计为最近 90 天活动摘要及可验证累计汇总；较早明细合并需保留去重与可恢复会话边界。实施 T49 时验证容量与压缩规则，不能静默丢弃旧记录。首次界面仅展示最近 7 天。
5. 统计记录与学习进度分离，不修改原 FSRS 评分；同作用域串行写入。两者不能原子写入时保留可重放断点并分别报告失败；统计写失败不得清除断点、阻止退出或伪称统计已更新。
6. 老用户继续显示已存在的累计看过/收藏/卡片；新增明细明确“详细记录从此版本启用后开始”。更早区间标“暂无详细记录”，不填成零活动，不从 cards/applied 推算独立或协助历史。
7. 备份导出、导入预检、恢复、旧备份兼容、学员删除范围与跨标签页同步一并覆盖新记录。即使备份工具匹配 v3 前缀，也需显式校验新结构与作用域；不得把未经校验 JSON 直接显示为统计。
8. 缺失/移除条目保留原历史，当前地图只映射当前有效内容；历史活动按当时课程版本解释。页面切换取消旧请求，禁止另一课程或学员的数据闪入。

编号与主 PLAN 同步；依赖顺序：T48 → T49 → T50 → T51 → T52 → T53 → T54 → T55。每项更新进度，代码和测试完成后才勾选。

## 7. 分批交付与估算

- 第一批 T48–T50：入口和可信数据底座，预计 3–5 人日。
- 第二批 T51–T53：两门旅程和首版记录页，预计 4–6 人日。
- 第三批 T54–T55：动效、兼容与回归，预计 2–3 人日。

单名熟悉项目开发者的初步工程估算共 9–14 人日，不含新插画生产、人工教学审校、真机安排和家庭试用；T49 完成后根据存储复杂度重估。无需等人工内容审校才能开发，但功能完成不能改变内容的待审校状态。较长时间趋势、时长细分、正确率变化放在首版稳定后，避免一次加入大量指标。

## 8. 验证与交付边界

自动测试覆盖正确率分母、题型资格、协助升级、共读、刷新/重放幂等、跨日与后台时间、多标签页、配额不足、旧备份与损坏数据。隔离浏览器实际验证两课程从首页开始、完成/暂停、返回后地图更新、打开记录、切换学员、导出恢复；检查桌面/375px、浅色/深色、减少动态、键盘、无声音和媒体失败。

工程检查沿用 npm test、npm run check:atlas、npm run build。性能与现有课程加载基线比较，地图按需渲染，不让雅思首页加载两门课程或全部图片。人工教学审校与真机发音继续单列，不因这轮完成而提前宣称正式发布。已执行的检查和尚未完成的验收以执行进度为准。
