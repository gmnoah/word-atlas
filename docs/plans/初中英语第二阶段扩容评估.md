**前置基线**：T59–T67 已全面完成 100 词标杆课程（`middle-english`，10 单元 × 10 词）工程研发、契约校验、独立策略调度、语境题型与端到端回归验收。  
**结论摘要**：**建议维持当前 100 词精品样板为第一阶段正式发布范围；第二阶段扩容至 300 词（增补 20 单元 200 词）已有候选主题与工程契约准备，但必须等待第一阶段真实学生/教师反馈并完成人工教学审校后再行启动。** 严禁脱离教研人力盲目承诺全量 1,600–2,000 词课标词库。

## 1. 标杆体验与研发成本复盘

### 1.1 认知负荷与学习策略验证

- **策略参数**：初中独立策略采用 `5 新词 / 15 复习 / 3 词一组 / 12 分钟上限 / speed-independent 计分`。
- **效果反馈**：
  - “3 词一组先识后练”有效降低了长短时记忆跨度过大的遗忘率，既避免了小学 2 词过慢，又避免了一次性灌输 5 词导致的挫败感。
  - 语境选义题（`context-meaning`）直接结合了初中阅读理解与完形填空的实战场景，改变了单纯中英对翻的机械背词模式。
  - 常用搭配（`collocation`）作为即时反馈与词卡标配，切实强化了词块（lexical chunk）意识。

### 1.2 单词制作与审校成本

| 制作环节 | 每 10 词平均耗时 | 质量关键点与难点 |
| --- | --- | --- |
| **词汇分级与义项锁定** | ~0.5 小时 | 必须剔除小学基础义项，锁定初中阶段最常考核心义项。 |
| **真实语境例句编写** | ~1.0 小时 | 句子需自然且语法严密；`targetForm` 必须整词匹配例句实际形态。 |
| **平行干扰项与解析编撰** | ~1.5 小时 | 干扰项必须同词性、无荒谬卡通感、有真实混淆度但语境唯一正确。 |
| **常用搭配提取与校对** | ~0.5 小时 | 优先选用中考高频动宾、介宾或形容词搭配。 |
| **工程录入与自动化审计** | ~0.5 小时 | 运行 `check:courses` 与 `npm test`，确保 0 契约冲突与 0 重复选项。 |
| **人工教学专家双盲审校** | ~1.5 小时 | 适龄性审查、例句真实感评估与配图意境核对。 |
| **合计（每 10 词）** | **约 5.5 小时** | **100 词累计工时约 55 人时；300 词预计需 165 人时。** |

## 3. 扩容技术准备与性能安全策略

1. **路由与按需加载**：当前 `middle-full.ts` 已经采用 Vite 动态 `import()` 按课程路由懒加载，全量 300 词打包尺寸预计增加约 180KB，对首屏雅思词光主站性能影响为 0。
2. **断点持久化与向前兼容**：`src/courses/primary-checkpoint.ts` 与 `src/learning/persistence.ts` 已内置词库版本协商机制（`contentVersion`），即使未来升级到 `0.2.0-draft`，历史旧版本未完成断点仍可安全修复或平滑结算。
3. **分层分级防污染**：初中存储 key 独立为 `word-atlas:v3:primary-progress:<learner>:middle-english`，无论词库扩展到多少词，均不会污染小学英语、汉字或雅思开放词库。
