# P0 样板模型与流程

状态：工程契约与交互样板，不是正式课程。对应 T03–T05。

## 模型契约

代码准源：`src/courses/types.ts`。现有雅思 Entry、Atlas、v2 存储不改名、不迁移。

| 对象 | 必填 | 规则 |
| --- | --- | --- |
| LearnerProfile | id、nickname、createdAt | 仅契约，P1 才实现多学员；不要求实名和生日 |
| CourseManifest | id、version、title、subject、stage、status、description、attribution | 稳定课程 ID；版本与 ID 分开；未上线阶段不能开始 |
| Lesson | id、title、subtitle、entryIds | ID 唯一，引用存在；实际活动数量可以低于小课条目数 |
| EnglishEntry | id、kind、topicId、word、meaning、example、media、reviewStatus、caregiverTip | kind=english；例句英文和译文都必填 |
| HanziEntry | id、kind、topicId、character、pinyin、phrase、sentence、question、media、reviewStatus、caregiverTip | kind=hanzi；拼音仅在家长区域展示；字形和语境读音独立于英语字段 |
| ContentMedia | image、recording、locale、source | 图片/录音缺失明确为 null；相对应用根路径；普通话不得套用英文口音 |
| ProgressIdentity | profileId、courseId、contentId | 未来正式进度使用；本样板不写入此数据 |
| AttemptResult | outcome、contentId；作答还需 correct、support | 跳过、媒体失败与有效答题分开；独立、提示、家长协助分开 |

草稿完整性与可发布性分别校验：30 个英语词、20 个汉字可以作为设计草稿；媒体未齐、设备语音未验证、未人工审校的条目不能标为可发布。

## 本次样板边界

- 路由为 `#/explore`，原雅思入口与旧链接保持原行为；原今日页增加入口。
- 新内容按路由懒加载；共用现有主题、Logo、插画、按钮和 Sheet。
- 英语预览复用原项目对应单词图片和英音；短句为新编草稿，不复用不匹配的雅思例句音频。
- 汉字预览复用可对应语义的现有插画；普通话采用设备朗读预览，失败可亲子朗读，不假装已有审校录音。
- 学习活动只保存当前页面内存，刷新返回样板首页；不记录正式进度，不运行 FSRS，不模拟多学员已完成。
- 家长设置只控制本次样板活动的条目数量和朗读语速；刷新恢复默认；正式持久化安排在 P1。
- 不把听音失败记为错误，不自动发起远程合成，不上传音频。

## 页面流程

1. 学习空间首页：三空间，雅思回原首页、小学和汉字进入主题课程；初高中标记后续开放。家长设置可从首页进入。
2. 课程页：主题小课、草稿条目预览；选择小课开始。返回学习空间不改变旧进度。
3. 初见 / 共读：图、词或字、短句、朗读按钮；“认识了”前进，“先跳过”跳过本条。汉字有家长互动提示。
4. 回忆：英语看图选词；汉字根据生活问题找字。至少两个独立选项。给出温和反馈，第一次提交后锁定，不重复计数。
5. 结果：区分接触、独立答对、协助、跳过；不使用“已经掌握”。返回课程或重新体验。
6. 中途离开：明确结束当前体验，可继续当前小课；不丢弃其他课程真实进度。浏览器刷新会结束样板并在入口说明。
7. 异常：图片失败显示既有文字版画；图像缺失的回忆活动不能正常计分，可跳过。语音不支持/失败显示亲子朗读建议；空课程/无条目显示返回入口，不崩溃。

## 样板进入下一阶段的条件

工程：类型、条目引用和资源检查通过；桌面/窄屏与双主题操作验证；旧雅思行为不变。

内容：30/20 条草稿逐条审校、录音齐备且语义一致，才可勾选 T04 的完整验收。尚未完成时保留待办，不因能点击而声称正式学习闭环完成。
