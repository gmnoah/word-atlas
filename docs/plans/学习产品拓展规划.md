# 词光学习产品拓展规划（PRD）

日期：2026-10-27。状态：规划草案，可进入技术设计；尚未实施。

配套执行清单：[开发实施计划](./开发实施计划.md)。

## 1. 产品决策

将现有“雅思单词图鉴”拓展为一个应用内的三个学习空间：雅思英语、基础英语、汉字启蒙。共享图文音频、练习会话、本地存储和复习能力，按学习阶段分别配置内容与交互。

基础英语覆盖小学、初中、高中三个阶段；首发优先小学，初中和高中逐步上线。幼儿汉字定位为亲子共读与生活识字，不设必须完成的识字量，不以默写或限时测试为核心。

保留现有网页、静态部署、本地优先的方向。先完成一套可用的学习闭环，再扩充词库。不在第一阶段拆成三个独立项目，也不先搭建账号、后台和支付系统。

### 默认假设

- 面向中国大陆家庭，汉字使用简体字和普通话；英语保留英美音能力，儿童界面只展示当前选定的一种。
- “中学生”包含初中和高中。年级用于推荐，不代表学生实际能力。
- 首版为自编主题课程，不声称同步某一出版社教材，也不把 CEFR 直接换算为年级。
- 预算、团队和指定教材尚未给出；以下范围、进度与数量都是产品建议，不能当作课标要求或交付承诺。

## 3. 人群与课程体系

### 3.1 基础英语

| 阶段 | 学习重点 | 核心交互 | 内容扩展建议 |
| --- | --- | --- | --- |
| 小学启蒙，参考 1–2 年级 | 听懂常见词、图物对应、简单口头表达 | 听音选图、看图听词、亲子跟读 | 先做生活主题；字母与发音作为独立小单元 |
| 小学基础，参考 3–4 年级 | 认读常见词、理解短句、初步拼读 | 看图选词、听音辨词、字母拼组 | 以家庭、学校、食物、身体、动物等主题组织 |
| 小学进阶，参考 5–6 年级 | 拼写、搭配、简单句子理解 | 补句、听写、拼写、短句选择 | 增加生活对话和词形变化 |
| 初中基础与进阶 | 高频词多义、搭配、语境辨义、词形 | 语境选义、补句、听写、错词复习 | 按主题和能力组织，可后续添加教材映射 |
| 高中基础与进阶 | 抽象词、词族、较复杂语境和阅读迁移 | 搭配辨析、句中词义、拼写与短阅读 | 与雅思建立内容关联，不直接共享掌握状态 |

课程结构：学习空间 → 阶段 → 主题单元 → 小课 → 学习条目。阶段切换可以建议补基础，但不强制孩子通过分级考试才允许学习。

内容规模规划：小学首版 300 个去重词；验证后小学逐步扩展到约 800–1,000 个。初中包拟包含约 1,600–2,000 个词，高中包拟包含约 3,000–3,500 个词，阶段包会重叠，不能相加作为独立总词数。中学最终范围在课程审校阶段确定。

自然拼读不等同于背词，也不能覆盖所有不规则词。后续单独安排字母音、常见字母组合和例外词，不用错误规则解释发音。

### 3.2 幼儿汉字

| 阶段 | 产品目标 | 活动形式 |
| --- | --- | --- |
| 3–4 岁，亲子陪伴 | 在生活和故事中对文字产生兴趣 | 指图听故事、找实物、家长读词；不设识字配额 |
| 4–5 岁，兴趣探索 | 认识熟悉场景中的部分字词 | 听词找字、字图配对、生活找字 |
| 5–6 岁，阅读准备 | 在短句和故事中辨认、理解字词 | 找字小游戏、词语搭配、简短共读；可观看笔顺 |

首版 100 个核心字，作为可选资源库，不是儿童必须完成的目标。后续按验证结果扩展到 300 个，再考虑 500 个。

主题示例：我的身体、我的家、动物朋友、自然天地、吃饭喝水、出门交通、数字与方位、日常动作。一个字可以跨主题出现，但只建立一份课程内识别进度。

字卡包含：规范大字、具体场景图、普通话字音、常用词、可朗读短句、家长互动提示。拼音默认放在家长详情，不让不会拼音成为学习障碍。首版回避脱离语境的多音字辨读；多音字后续按“字 + 词语读音”组织。

教育部对《3–6 岁儿童学习与发展指南》的解读强调在生活和阅读中培养文字兴趣，反对机械记忆、强化训练式的过早识字。因此本产品将共读与生活活动放在主线，识别练习只作补充。[教育部原文](https://www.moe.gov.cn/jyb_xwfb/s271/201210/t20121015_143257.html)

## 4. 学习闭环与评分

共同流程：选择学员和课程 → 今日小课 → 看图听音初见 → 主动回忆 → 温和反馈 → 后续复习 → 展示本次收获。

| 配置 | 小学启蒙 | 小学进阶 | 初高中 | 幼儿汉字 |
| --- | --- | --- | --- | --- |
| 建议单次时长 | 5–8 分钟 | 8–12 分钟 | 10–15 分钟 | 3–5 分钟，可随时停止 |
| 默认新内容上限 | 3 个 | 5 个 | 10 个 | 2 个，可只共读 |
| 初见分组 | 2–3 个 | 3–5 个 | 5 个 | 1–2 个 |
| 复习数量上限 | 8 个 | 15 个 | 30 个 | 4 个 |
| 拼写 | 关闭 | 逐步开放 | 开放 | 无 |
| 主要反馈 | 找到了、再听听 | 正确与提示 | 正确、提示与解释 | 陪伴、发现、再试一次 |

这些时长与数量是待试用验证的初始参数，不是医学建议或教学定额。达到上限时正常结束，剩余复习顺延；不展示“欠了多少任务”。家长可以减少任务，孩子可以提前结束。

评分原则：

1. 雅思先保持原有行为；新儿童模式答题速度只用于体验分析，不决定记忆分数。
2. 独立答对记为 Good，提示后答对记为 Hard，明确答错记为 Again；跳过、停止、资源失败不计错。
3. 同一条目一次会话只有第一次有效回忆更新记忆与正确率，后续重试仅为练习。
4. 首版每条目保留一份“识别复习状态”，拼写练习另记表现，不声称识别正确等于会写。
5. 幼儿可保留内部复习调度，但界面不展示稳定度和掌握率，不承诺算法已针对幼儿得到验证；共读浏览不计入答题正确率。
6. 家长协助的题目要标记 assisted，不计入独立答对率；首版不更新独立识别卡，后续安排独立尝试。
7. 儿童选项从 2 个起步；图片题不能把英文或答案藏在图片上；汉字题不能所有选项都带明显图示而仅测出图片识别。
8. 题目生成须检查媒体能力；没有可用音频时不得给出纯听音题，没有合适干扰项时切换题型，不用重复选项凑数。

## 5. 具体小课示例

### 小学英语：My fruit（apple、banana、orange）

先展示苹果图并播放 apple → 听 apple 选择对应图片 → 看图从 apple/banana 中选词 → 听懂 “I like apples.” → 显示今天认识的词，邀请孩子在家里找一种水果。下一次复习替换图片或排列顺序，避免只记住位置。

apple 的首次作答只记录一次，后续短句练习不再次更新该词的 FSRS。句子采用自然词形，系统以明确目标标注识别 apples，不能简单依赖字符串替换挖空。

### 初中英语：borrow / lend

先用校园借书场景解释方向 → 在 “Can I borrow your pen?” 中选词 → 换语境辨别 lend → 给出常见搭配 → 另行拼写练习。不同词义和技能的拆分作为后续扩展，首版不把一道选择题当作全部用法已掌握。

### 幼儿汉字：“山”和“水”

家长和孩子看山水场景 → 点击听“山”“水” → 家长读“小河里有水” → 听“水”在两个大字中找一找 → 结束时提示“去找找家里的水在哪里”。不强制写字，不给倒计时，不要求答对才能退出。

## 6. 信息架构与体验

首页：选择学员 → 三个学习空间 → 当前课程与“继续学习”。首次进入仅选择阶段、每天大致学习量与声音，不要求真实姓名、生日或学校。

学生导航：今日、图鉴、练习、我的。幼儿导航：今天玩什么、字卡、家长；练习嵌在故事和小课中，家长区域采用简单操作门槛防误触，该门槛不宣称为身份验证。

关键页面：

- 学习空间与课程选择：显示适用阶段、内容量、下载状态、最近学习；未上线课程明确标识，不出现空白学习页。
- 今日：一个主按钮，一张当前任务卡；复习与新课自动组合。
- 英语词卡：低龄先看图和听音，较高阶段展开释义、例句、搭配。
- 汉字卡：大字与图分区，字形清晰；幼儿使用中性、易辨识的字体。
- 学习结果：展示“今天接触/练习了什么”；鼓励回到生活，不自动无限续关。
- 家长面板：选择学员、调整时长/新内容、查看近期活动、备份恢复；不做班级排名。

保留原项目温暖的图鉴风格。幼儿使用更简洁的场景、更少文本、更大的操作区；中学生降低幼稚感。动效可关闭，声音按钮可见，断网和无声音都要有可理解的反馈。低性能设备使用二维主题地图，不强制加载 WebGL 星图。

## 8. 用户故事

1. 作为现有雅思用户，我希望升级后保留进度、收藏和设置，以便继续学习。
2. 作为家长，我希望为不同孩子创建昵称档案，以免学习记录混在一起。
3. 作为家长，我希望选择实际能力对应的课程，而不被年龄硬性限制。
4. 作为小学生，我希望听声音选图片，在不认识中文解释时也能完成练习。
5. 作为小学进阶学生，我希望逐步学习拼写，不一开始就被大量打字阻碍。
6. 作为初中生，我希望在句子里辨析词义和搭配，让词汇能用于阅读。
7. 作为高中生，我希望学习抽象词和词族，并逐步衔接雅思学习。
8. 作为幼儿，我希望通过听故事和找字参与，不依赖拼音和键盘。
9. 作为家长，我希望得到生活互动提示，把屏幕学习延伸到真实物品和共读。
10. 作为学习者，我希望答错后获得示范和重试，而不是被扣分惩罚。
11. 作为学习者，我希望随时暂停，恢复后不会重复计分。
12. 作为家长，我希望提示或协助后的答题与独立答题区分开。
13. 作为家长，我希望切换学员或课程不会覆盖其他人的记录。
14. 作为家长，我希望导出全部本地档案，恢复前知道会影响哪些数据。
15. 作为学习者，我希望在音频加载失败时能重试或跳过，不被判错。
16. 作为内容编辑，我希望找到未审校、媒体缺失和版本异常的条目。
17. 作为内容维护者，我希望修正插画或音频而不让用户重复学过的全部内容。
18. 作为使用旧链接的用户，我希望原有雅思词卡地址仍可打开。

## 9. 技术设计决策

### 9.1 共享核心、分科适配

维持现有技术栈。新增课程注册表、学员管理、课程包加载器、学习策略和题型注册表。英语卡与汉字卡独立渲染；避免在所有组件里散落年龄和学科判断。

内容模型使用有类型区分的英语条目与汉字条目，共用稳定 ID、主题、资源清单和内容版本。汉字字段包含字形、语境读音、词语、例句与可选笔顺引用；不伪装成英文单词，也不滥用 CEFR 字段存汉字等级。

建议核心对象：LearnerProfile、CourseManifest、EnglishEntry、HanziEntry、Lesson、LearningPolicy、Progress、Session。课程包声明学科、阶段、前置小课、支持题型、版本、资源和署名信息。

能力接口：课程加载器提供 manifest/entry/media 查询；学习策略决定内容选择、题型资格、会话上限和评分；题型模块负责显示与提交结果。保持本地函数边界，首版不增加 HTTP 业务服务。

### 9.2 身份、进度与迁移

- 内容身份为 contentId，课程身份为 courseId，学员身份为 profileId；不把版本号编码进稳定内容 ID。
- 首版进度主键为 profileId + courseId + contentId，设置分为设备设置、学员偏好和课程学习设置。
- 同一个 apple 可在不同课程复用媒体，但课程进度默认独立；跨课程免学需要未来显式确认。
- 未来如细分听辨、识读、拼写，新增 skillId；不把旧识别卡直接复制为所有技能都掌握。
- 旧 v2 数据迁移到默认学员的原雅思课程；保留卡片、历史、收藏、错词和有效会话。无效旧会话可舍弃，但须保留学习历史并提示。
- 迁移先备份，校验后写入 v3，最后写完成标志；失败保留 v2 并允许回退，重复执行不重复导入。
- V1 保持 localStorage 以控制改造量，增加写入失败提示与容量监测；大规模日志或云同步前再评估 IndexedDB。
- 导入备份先预检学员、课程、版本与覆盖范围，再由用户选择导入为新档案或替换目标；不能静默覆盖全部进度。
- 切换课程前完成旧状态落盘，取消旧资源请求；异步返回必须核对课程/学员，防止旧课程题目写进新进度。

### 9.3 内容路径与离线

旧雅思数据保留现有路径并由适配器读取；新课程使用带课程 ID 与内容版本的路径。课程清单指向确定版本，不允许索引与词条来自不同版本。

缓存按应用范围和课程版本管理，不能清理同源其他应用缓存。已缓存可离线继续；未缓存小课给出缺失提示。V1.1 才承诺主动下载整课，并展示大小、进度、失败重试和删除入口。刷新升级期间的旧会话需绑定内容版本，无法恢复时安全结束并保留已完成记录。

## 10. 内容生产与质量门槛

流程：主题和学习目标 → 词/字清单 → 原创文本 → 教研审稿 → 插画与音频 → 全量内容检查 → 儿童小范围试用 → 版本发布。

首版建议配置一名开发者、英语审校者和幼儿内容审校者；角色可兼职，但内容审校不能由结构校验替代。AI 用于草稿和素材生产，不能直接将未审校输出投入儿童课程。

每条内容的发布条件：

- 学习目标与阶段明确，释义和句子可理解，图片准确对应目标。
- 英语音频与词形、例句一致；不使用只因包含某个词就适配给儿童的成人场景。
- 汉字为规范字形，普通话读音正确；故事说明不能冒充字源学解释。
- 干扰项存在唯一正确答案；近义图像、同音字和多音字由审校者判断歧义。
- 必需媒体可加载，无占位链接；每个条目保留审校人、状态、版本与来源记录。
- 复用原项目资源保留项目的内容署名信息；新增字体、笔顺、音频和图片记录其来源与使用条件，未核实的资源不进入发布包。

先完成 30 个小学词和 20 个汉字的样板包，验证文本、画面、声音与练习的一致性，再批量制作 300/100。300 个英语词每个至少一图、单词音频、例句音频；100 个汉字每个至少一图、字音和词/句朗读，即最低约 400 张图与 800 段音频，不含缩略图、双口音和返工。

## 11. 验收与效果评估

工程发布门槛：旧雅思回归通过；多学员与跨课程数据隔离；迁移、恢复、资源失败和中断续学可验证；没有阻断性缺陷；发布内容 100% 完成文本、图片和音频审校。

学习效果与体验分开统计：首次独立作答正确率、隔天回忆表现、提示使用率、完成/主动结束次数、家长观察。图文浏览和共读不能混作独立识字成绩。

试用建议：邀请 8–12 个家庭，经家长知情自愿参与，试用两周；涵盖低龄小学、较高年级小学和幼儿。默认通过本地导出摘要与访谈获得反馈，不暗中增加远程追踪。

内部体验目标：至少 80% 试用家庭能在首次引导后顺利开启小课；80% 会话无技术阻碍地完成或正常主动结束。样本很小，结果用于发现问题，不宣传为学习效果证明。延期发布条件：普遍需要家长解释按钮、内容歧义、孩子明显挫败，或旧进度丢失风险。

## 12. 成本、风险与演进

首版主要成本不是页面，而是适龄内容和逐条审校。预算采用公式：开发人日 × 日成本 + 审校工时 × 时薪 + 图片/语音实际生成成本 + 返工 + 静态存储与流量。先用 30/20 样板记录单位成本，再估算 300/100；预留约 20%–30% 返工空间，这是估算假设。

| 风险 | 应对 |
| --- | --- |
| 同时覆盖所有年级导致首版失控 | 先小学和汉字，初高中明确列入后续交付 |
| 内容量大但不适合孩子 | 先样板试用，再扩大生产 |
| 英语模型限制汉字 | 分科数据与题型适配，共用会话和存储 |
| 复习量变成压力 | 时间/数量上限、跳过、家长控制、无欠账提示 |
| 升级丢失旧记录 | 幂等迁移、旧数据保留、备份演练和兼容验证 |
| 本地记录受浏览器清理影响 | 明确本地保存边界，提供全档案备份提醒 |
| 媒体使首屏变慢 | 先加载课程清单与当前小课，图片音频按需读取 |

长期顺序：小学与汉字闭环 → 初中与自然拼读/阅读 → 高中与跨阶段衔接 → 根据真实需求决定账号同步、学校场景或商业化。
