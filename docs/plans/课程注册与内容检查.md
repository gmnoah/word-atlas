# 课程注册与内容检查（T06 / T04 补充）

日期：2026-10-27。课程注册已实施；内容仍为草稿，不等于 P0 或 P1 整体完成。

## 课程注册的唯一来源

`src/courses/registry.ts` 保存课程身份、阶段、状态、封面和入口类型。注册表只包含元数据，不导入词条或媒体。

| 稳定 ID | 课程 | 状态 | 行为 |
| --- | --- | --- | --- |
| word-atlas-open | 雅思英语 | available | 保留原 `#/`，不改变 datasetId、资源或进度 |
| primary-starter | 基础英语 | preview | 打开小学样板 |
| hanzi-starter | 汉字启蒙 | preview | 打开汉字样板 |
| middle-english | 初中英语 | planned | 显示待开放，没有学习入口 |
| high-english | 高中英语 | planned | 显示待开放，没有学习入口 |

首页课程卡、待开放列表以及样板包 manifest 共用注册元数据。`courseAction` 对未知 ID、待开放课程返回 unavailable，不能生成学习操作。样板资源仍在原路径，不更改雅思加载器；T07 将另行实现统一数据适配。

## 两种检查

- `npm run check:courses`：草稿可运行检查。验证课程注册、封面、条目 ID、小课引用、必需文本、媒体语言、声明的媒体路径及文件存在性。缺少尚未制作的媒体列为发布阻断项，不阻止设计样板运行。
- `npm run check:courses:release`：在上述检查之上要求图像、词/字录音、例句录音齐全，每条内容有 approved 状态以及文本、图片、音频的人工审校人和日期记录。不满足时退出码为 1。

这是工程检查，不会自动判断插画与词义是否准确，也不能证明审校记录真实性。生产发布流程仍应核对实际审校，不能仅把状态改成 approved。

## 本次实际结果

注册 5 门课程，两个体验包共 50 条内容。草稿结构错误为 0；正式发布有 120 项阻断：

| 类型 | 数量 | 说明 |
| --- | ---: | --- |
| 待人工审校 | 50 | 30 个英语词、20 个汉字，均保留 draft |
| 缺词/字预录音频 | 20 | 汉字当前采用设备朗读预览 |
| 缺例句预录音频 | 50 | 新编英语短句和汉字短句没有匹配录音 |

这 120 项是检查项数量，不是条目数量。普通话字音补齐后仍需处理例句与教学审校，不能直接勾选 T04。

`样板音频与审校清单.csv` 含 100 行待审校音频目标（50 个词/字 + 50 条例句），列出准确文本与已有文件。仅 30 条英语词音已有录音；70 条音频目标待制作。审校人和日期为空，不能用自动化结果伪填。

## 后续使用

1. 按清单制作缺失音频，记录可再分发的来源与许可，核对发音和文本。
2. 将文件路径填入 `media.recording` / `media.exampleRecording`。例句音频必须与当前文本一致。
3. 由实际审校者逐条检查文本、插画、词音与句音，留下记录；完成后再更新 `humanReview` 和 `reviewStatus`。
4. 重跑草稿与发布检查；修复所有结构错误及发布阻断后，才能进入内容发布验收。

本次没有调用付费音频生成、没有上传儿童数据、没有伪造人工审校记录。技术侧可继续 T07 的数据加载适配；内容侧继续 T04，正式发布仍受内容检查约束。
