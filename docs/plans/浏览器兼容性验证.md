# 浏览器兼容性验证

当前结果：本机桌面 Chrome 156 在隔离浏览器上下文中通过英语与汉字课程、图片显示、普通话声音不可用提示、退出、375px 和桌面布局及主题切换检查。此结果不是手机真机验收，也不能代表 Safari 或 Firefox。

Safari 已安装，但当前自动化环境读取窗口失败；本机未安装 Playwright 的 Firefox 和 WebKit 浏览器，本次均未验证。真实设备、不同浏览器声音和网络表现仍待测试。

可在已有对应浏览器的环境中，先使用 `npm run build` 构建，然后启动仅本机访问的生产预览：

```sh
npm run preview -- --host 127.0.0.1 --port 5199 --strictPort
```

另开终端运行需要的检查：

```sh
npm run check:browser
BROWSER_ENGINE=firefox npm run check:browser
BROWSER_ENGINE=webkit npm run check:browser
```

脚本默认使用已安装的 Chrome；Firefox 和 WebKit 需要环境中预先有 Playwright 对应浏览器。检查使用独立上下文及模拟无普通话声音，不清理或访问现有浏览器学习记录。脚本不验证真实设备的语音音色、实际网络、系统输入法或家庭试用体验；需另行记录设备、浏览器版本与结果。
