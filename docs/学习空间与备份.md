# 学习空间与备份

词光保留原来的雅思词库和学习入口。首页的“打开学习空间”提供小学英语和汉字启蒙体验；初中、高中课程尚未开放。两门儿童课程目前是草稿样板，内容与媒体尚待人工教学审校，不能作为正式发布内容。

基础英语和汉字启蒙的图鉴与学习入口目前各包含 300 条内容，均标为待审校。学习空间中的“检查课程内容”是本机开发环境的检查入口，可搜索并查看当前课程内容和资源；它不记录学习进度，也不包含在生产发布中。

小学英语可以从主题开始，也可进入今日小课：系统先安排适合回顾的词，再加入新词。词卡可收藏；中途离开或刷新后，再次打开同一小课可继续。初见、提示、家长协助与独立回忆是不同的学习行为，不等同于已经掌握。

汉字启蒙以亲子共读和找字为主，可以在家长区调整学习数量和时长。当前汉字词语使用设备普通话朗读预览；是否有合适声音取决于设备，也可以由家长读一读。

## 旅程、图鉴和学习记录

在学习空间选择课程后，可以进入“今日旅程”“主题图鉴”或“学习记录”。旅程会展示部分主题和实际看过的状态；选择“查看全部主题”可以访问全部课程内容。图鉴里的词或字可以点击查看图片、释义或词语与朗读，查看详情本身不记录识别成绩。旧课程链接仍可打开主题图鉴。

英语今日小课有有效未完成记录时可继续；汉字旅程会提供有效的共读续学入口。主题中也可以自行选择小课或共读，随时返回。设备不支持普通话朗读或资源加载失败时，可以请家长读一读或跳过。

学习记录按学员与课程分别保存在本机。家长可以查看看过的内容、主题足迹和记录启用后的首次答题情况；独立、提示和家长协助分开显示。看过或答对不代表已掌握。近七天按已保存日期显示识别作答和共读；较早未保存日期的活动不补造，跳过及资源故障不算答错。初见跳过与识别题首次跳过分开列出，重试的跳过和故障另行显示，不计入识别题首次结果。

## 学员和本机记录

在学习空间的“家长设置”中可以创建昵称并切换学员。学习记录保存在当前浏览器设备，不需要账号，也不会自动同步到其他设备；浏览器清理网站数据、卸载或设备损坏可能导致记录丢失。遇到保存失败提示时，请先导出备份。多标签页安全保存依赖浏览器锁；不支持时页面会提示。

## 导出和恢复

1. 在学习空间的家长面板选择“导出全部档案”，将下载的备份妥善保存。原雅思页面的“我的”也提供同一全量导出入口。
2. 需要恢复时，选择备份文件。页面会先说明将替换的词光数据范围；建议先导出当前设备的备份，再确认恢复。
3. 恢复完成后按页面提示刷新。备份包括当前设备的词光学员档案、课程设置及学习记录，不包含其他网站的数据，也不会自动上传。

## 内容制作与检查

`npm run prompt:course -- primary-english apple banana` 和 `npm run prompt:course -- preschool-hanzi 山 水` 只生成草稿提示词，不联网、不产生新内容或审校记录。`npm run check:courses` 检查样板结构；`npm run check:courses:release` 还要求媒体和可追溯人工审校，未满足时会以非零状态退出。检查外部课程文件可用 `npm run check:courses -- --input 文件.json --expected-version 版本`，如需执行发布门槛，再加 `--release`。自动检查不替代人工评估适龄性、图文匹配、录音质量和授权。
